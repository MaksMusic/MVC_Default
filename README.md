# Инструкция по запуску и деплою проекта

Данный проект поддерживает запуск в локальном окружении через Docker и автоматизированный деплой на удаленный сервер.

## 📋 Требования

- Docker и Docker Compose
- Доступ к серверу по SSH (для деплоя)
- Windows (для запуска `.bat` скриптов) или Bash-терминал

---

## 🐳 Запуск через Docker (Локально)

1. **Настройка переменных окружения**

   Откройте файл `docker-compose.yml` и убедитесь, что в сервисах `db` и `app` прописаны корректные учетные данные для
   подключения к базе данных:

   ```yaml
   services:
     db:
       environment:
         SPRING_DATASOURCE_URL: jdbc:postgresql://db:5432/mvcdb
         SPRING_DATASOURCE_USERNAME:login
         SPRING_DATASOURCE_PASSWORD:password
     
     app:
       environment:
         SPRING_DATASOURCE_URL: jdbc:postgresql://db:5432/mvcdb
         SPRING_DATASOURCE_USERNAME:login
         SPRING_DATASOURCE_PASSWORD:password

## Деплой на сервер (Beget)

2. **Для автоматического развертывания проекта на удаленный сервер используйте скрипт deploy-beget.bat**
   - Откройте терминал в корне проекта.
   - Запустите скрипт деплоя:
   - ./deploy-beget.bat


```При появлении запроса введите данные для подключения```
   - Введите IP адрес сервера: 123.45.67.89
   - Введите пользователя: root
   - Введите путь для копирования файлов: /app
   - Введите пароль от сервера

``` После успешного запуска или деплоя сервис будет доступен по адресу:```
- 👉 http://ваш-ip:8181
- Пример: http://123.45.67.89:8181
